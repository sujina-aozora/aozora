AOZORA Inc. corporate website / 株式会社青空 コーポレートサイト
================================================================

■ 閲覧方法
  このフォルダ内の index.html をブラウザ（Google Chrome 推奨）で開いてください。
  サーバーやインストールは不要です。ダブルクリックで表示できます。

■ How to view
  Open index.html in this folder with a web browser (Google Chrome recommended).
  No server or installation is required.

■ ページ構成 / Pages
  index.html        ホーム / Home
  services.html     サービス（サービス診断を含む） / Services (with Service Finder)
  how-we-work.html  進め方・体制 / How we work
  parijat.html      ネパール開発拠点 Parijat / Nepal development centre
  works.html        実績 / Track record
  company.html      会社情報・グループ会社 / Company & group company
  contact.html      お問い合わせ・よくあるご質問 / Contact & FAQ

■ 補足 / Notes
  - フォント・アイコンはすべて同梱しており、オフラインでも表示されます。
  - 本サイトには送信フォームはありません。電話・メールのリンクは、お使いの端末の電話・メールアプリを起動します。
  - Fonts and icons are bundled; the site works offline.
  - The site has no form backend. Phone and email links open the device's own apps.
